Project Overview

This project is a fully functional, responsive web application designed to serve as a personal academic portfolio and an interactive student management platform. Built from scratch using semantic HTML5, advanced CSS3 (Flexbox, Grid, and custom motion animations), and vanilla JavaScript, it bridges executive operations management expertise with modern software engineering principles.

Key Features & Functional Modules

Homepage & Hero Section
Professional identity showcase with custom avatar display.
Quick statistics bar highlighting 5+ years of leadership and operations experience.
Smooth navigation menu linking all core sections.

Educational background in Software Engineering at Miva Open University.

Featured Projects

Interactive Academic Planner
Powered by native JavaScript arrays and DOM manipulation.
Allows students to add new study tasks, toggle task completion status, delete items, and track completion progress in real time.

Contact Form & Validation
Fully validated contact form ensuring no empty fields, proper email formatting, and strict digit-only phone number verification.
Technical Stack & Requirements Met
HTML5: Semantic structural elements, interactive forms, tables, lists, and hyperlinks.
CSS3: External stylesheet, responsive design principles for mobile/desktop interfaces, CSS Grid, Flexbox, custom variables, and @keyframes motion animations.
JavaScript (ES6+): Event handling, DOM updates, form validation logic, and state management arrays.
