## Project Overview
This project is a fully responsive, multi-page personal portfolio and interactive academic management platform. Built completely from scratch using semantic HTML5, advanced CSS3 (Flexbox, CSS Grid, custom variables, and @keyframes motion animations), and vanilla JavaScript (ES6+), the application bridges executive operations management expertise with modern software engineering principles.

Multi-Page Architecture & Core Features
The application is structured into five distinct, interconnected pages supported by a fully responsive mobile hamburger menu and a top utility status bar:

Homepage (index.html)
Professional identity showcase with custom avatar display (head.jpg).
Quick statistics bar highlighting 5+ years of leadership and operations experience.
Direct calls to action for project exploration and the academic planner.

About Me Page (about.html)
Educational background pursuing a BSc in Software Engineering at Miva Open University.
Motion Timeline: Animated career history highlighting leadership roles at Applyish AI, Digital Hospitality Hub, and Zeton Integrated Services Ltd.
Animated Skill Progress Bars: Visual percentage indicators for operations management, web design, leadership, and JavaScript.
Direct PDF Resume Download: Integrated button linking to resume.pdf.
Executive Endorsement Quote: Professional testimonial highlighting management impact.

Projects Page (projects.html)
Showcases real-world web applications with dynamic Category Filtering (Web Tech vs. Operations & Business).
BigBite Grill Web Platform: Features an interactive quick-order/catering modal for Abuja outlets.
Responsive Weather & Location Tool: Integrated standalone web utility (View Weather Tool Repo).

Academic Planner Page (planner.html)
Powered by native JavaScript arrays and DOM manipulation.
Allows students to add study tasks, toggle completion status, delete items, and track completion progress in real time.
Google Calendar Integration: One-click button next to each task that instantly generates a pre-filled Google Calendar event for scheduling and reminders.

Contact Page (contact.html)
Fully validated contact form ensuring no empty fields, proper email regex verification, and strict digit-only phone number validation.

Technical Stack & Enhancements
HTML5: Semantic structural elements, interactive forms, and structured lists.
CSS3: External stylesheet, responsive media queries, CSS Grid, Flexbox, custom variables, scroll-reveal intersection observers, and dark mode support.
JavaScript (ES6+): Event handling, DOM manipulation, localStorage state persistence for dark mode, live Abuja time interval clock, and interactive modals
